# journal mark tables

`MarkTables.generated.swift` carries the locked asset sets for the journal mark, generated from
[spl-core](https://github.com/solpbc/spl-rust/tree/main/crates/spl-core/assets/mark_assets). The mark must draw
the same everywhere, and the derivation selects by index, so entries are never reordered, added or removed.

- **Lucide icons:** a 60-icon subset. ISC License. Source: <https://github.com/lucide-icons/lucide>.
- **EFF Long Wordlist:** 7776 words. Creative Commons Attribution 3.0 US. Source: <https://www.eff.org/dice>
  ("EFF's New Wordlists for Random Passphrases", 2016).
- **Color list:** sol pbc; no third-party rights.
